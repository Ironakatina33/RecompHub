# Vérification de la v2 sur Windows

1. Extraire complètement `RecompHub-Windows-v2.0.0.zip`.
2. Ouvrir `RecompHub.exe` : une fenêtre d'application Microsoft Edge doit s'ouvrir.
3. Cliquer sur Personnalisation, changer de thème entre Neon, XMB Legacy, Blue Horizon, Channel Studio, Joy Home.
4. Ajouter un programme avec Ajouter un jeu, ou Scanner un dossier.
5. Vérifier jouer, favoris, modifier le nom, choisir une image, retrouver le dossier, retirer (ne supprime pas le jeu).
6. Fermer, rouvrir et vérifier que la bibliothèque et le thème choisis sont conservés.
7. Vérifier Mise à jour : si une version plus récente est publiée sur GitHub, proposer l'installation.

Log en cas d'erreur : `%LOCALAPPDATA%\RecompHub\v2.log`.

La compilation Windows a été vérifiée, mais aucun test d'ouverture sur un vrai PC Windows n'est possible depuis cet environnement.
