RecompHub v4 - Windows 10/11 64 bits
==================================

1. Décompresse l'archive dans un dossier de ton choix.
2. Double-clique sur RecompHub.exe (portable).
3. Si tu avais la v3, ta bibliothèque est conservée automatiquement.
4. Options > Choisir un thème : XMB (PS3) ou Chaînes (Wii).

Flèches : naviguer       Entrée : ouvrir une chaîne ou un jeu
Échap : retour          Ctrl+K : rechercher un jeu

La boutique installe uniquement les archives GitHub des projets sélectionnés.
Les données commerciales de jeux / ROMs ne sont jamais fournies.

L'application utilise Microsoft Edge en mode app et tente de supprimer la
barre Windows; selon la version de Microsoft Edge, la suppression peut échouer.

Si le programme ne démarre pas : lancer Diagnostic-RecompHub.cmd.
Données : %LOCALAPPDATA%\RecompHub\library.json
Logs : %LOCALAPPDATA%\RecompHub\v4.log
Dépôt : https://github.com/Ironakatina33/RecompHub
